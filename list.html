Список ресурсов в каталоге

В данном каталоге представлены следующие ресурсы:

  • Каталог apk-adb для файлов упрощения настройки телефона после его приобретенияю
  • Каталог Adjust содержит файлы для дополнительной настройки компьютеров под управлеием операционной системы Microsoft Windows различных версий.
  • Загрузка файлов для упрощения настройки телефонов вместе с инструкцией.
  • Install_apk_from_Unknown_Sources — файл с описанием правил установки apk файлов из неизвестных источников (дайджест из сети Интернет).
  • adb_install_and_setup — файл с описанием установки программы adb.exe и драйверов к ней. Только для опытных пользователей, разработчиков и администраторов!

Примечание для монтирования SMB Share

  1. Данный каталог желательно монтировать как временную общую папку SMB.
  2. На время её монтирования ОБЯЗАТЕЛЬНО отключите активную защиту своего антивируса.
  3. Не злоупотребляйти своими полномочиями при монтировании папки. Не удалйте и не добавляйте в неё ничего. Уважайте других пользователей!
  4. Данной шаре, для её корректной работы, необходимо назначить букву z:.
  5. Монтировать данную шару можно, например, при помощи следующей команды:
    6. 				net.exe use z: \\win.netip4.ru\TOWIN Admin01234 /USER:WIN\MSSQLSR
  6. После монтирования шары как диск z: вы можете выполнять стандартные файловые операции как и с локальным диском.
  7. После окончания работы размонтируйте шару и освободите букву z: командой:
    8. 				net.exe use z: /Delete
  8. Данные команды запускаются в окне терминала. Внимательно смотрите, под какой учётной записью и с какими привилегиями вы запускаете данные команды!
